# Fly Kai Tak

- Commit and push every update to `main` automatically. Permission is granted; do not ask.
- Every new feature or bug fix gets a blog post (see docs/blog.md), with screenshots, a URL stub, metadata, a category and share buttons, plus a Cantonese version (see docs/blog.md).
- When flying routes to create screenshots, toggle the cockpit off (`deck: false`; the Cockpit button in the sim). `tools/screenshot.py` does this by default.
- Follow the design system in docs/claude-project.md for any UI, web or marketing work.
- Test every change: the autopilot must still land in all weather presets, and flying with no input must still crash.
- Keep explanations brief and to the point.
