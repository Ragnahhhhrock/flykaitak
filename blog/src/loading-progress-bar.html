The home screen now shows a progress bar while Fly Kai Tak loads, with a percentage under it, so you can see how far along it is and roughly how long is left.

What you see

  • A bar and a percentage under the "Building Hong Kong" message. The first part is the map, terrain and aerial photos downloading; the rest is the city, airport, port and ships being built.
  • The bar moves after each stage, so the page no longer sits on one message for several seconds.
  • If the map data cannot load, or WebGL is not available, the message says so and the bar is hidden.

The autopilot still lands in every weather preset, and flying with no input still ends in a crash.
