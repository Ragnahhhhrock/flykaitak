Some players turned their phone sideways and the "Turn your phone sideways" prompt stayed on screen. This update makes the prompt follow the real window size and explains what to do when the phone will not rotate.

What changed

  • The prompt now checks the window's width and height directly, every time the window resizes, instead of relying only on a media query.
  • On iPhone and iPad it adds a hint: Still upright? Turn off Portrait Orientation Lock in Control Centre. With the lock on, the browser stays in portrait whichever way you hold the phone, so the prompt cannot clear.
  • Fly in portrait anyway still dismisses the prompt and resumes the flight.

Try this

If the prompt will not go away, open Control Centre, switch off the orientation lock, and turn the phone sideways. The flight resumes by itself.
