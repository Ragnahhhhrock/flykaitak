The upper-deck windows on the 747-400 were larger than the passenger windows on the main deck. They are now the same size, so the two rows read as one set of windows.

The flight-deck windows are also smaller, at about 0.6 m by 0.45 m, and the upper-deck hump is lower, so the 747 no longer looks top-heavy.

What changed

Each upper-deck window is now the same length and height as a main-deck passenger window. Their spacing along the hump is unchanged.

What did not change

  • Only the look of the 747-400 changed. Its size, weight and handling are the same.
  • Flying with no input still ends in a crash, and the autopilot still lands in every weather preset.
