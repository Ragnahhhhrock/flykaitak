An inverted yoke for touch and mouse: drag down to pull up

The on-screen yoke now works like a real control column: drag down to pull the nose up, drag up to push it down, with touch or a mouse.

The on-screen yoke now works like a real control column. Drag down to pull the nose up, drag up to push it down. Before, it was the other way round.

DownPulls the nose uplike the down arrow key
UpPushes the nose downlike the up arrow key
Touch + mouseSame controlone yoke for both

What changed

A yoke is pulled back to climb and pushed forward to descend. On the screen, "back" is toward you, which is down. The yoke now follows that: dragging the knob down raises the nose, and dragging it up lowers it. Dragging sideways still rolls, as before.

Touch and mouse

There is one yoke for both. On a phone or tablet you drag it with a finger. On a computer you click and drag it with the mouse. Both use the same direction, and it now matches the keyboard: the down arrow (or S) pulls the nose up, and the up arrow (or W) pushes it down.

If you flew with the old direction, expect to pull the other way. Pull back gently in the flare, and drag down a little at about 150 kt to rotate on take-off.

What did not change

  • The autopilot, thrust and flaps behave as before.
  • Flying with no input still ends in a crash, and the autopilot still lands in every weather preset.
  • The Controls list on the setup screen now describes the yoke direction.
